# Assignment 2 – Setup Proof (VS Code, Node.js, Live Server)

## Objective
To verify that VS Code, Node.js, npm, and the Live Server extension are installed and working correctly.

## Steps

### 1. VS Code
Open Visual Studio Code and go to **Help → About** to check the installed version.

### 2. Node.js and npm
Open the VS Code terminal using `Ctrl + `` and run these commands:

```bash
node -v
npm -v
```

Note down the version numbers displayed in the terminal.

### 3. Live Server
1. Open the Extensions panel using `Ctrl + Shift + X`.
2. Search for **Live Server** by Ritwick Dey.
3. Click **Install**.
4. Open an HTML file and click **Go Live** in the status bar.
5. Check that the webpage opens in the browser, usually at `http://127.0.0.1:5500`.
